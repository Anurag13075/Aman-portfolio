# Aman Sharma — Portfolio Website

> **Junior Accountant | Banking & Financial Operations Professional**

A modern, executive, fully-responsive personal brand website for **Aman Sharma**, tailored specifically for corporate banking, financial operations, audit readiness, and accounting.

---

## 🌟 Overview & Highlights

- **Executive Aesthetic:** Designed with Deep Navy (`#0B1F3A`), warm Gold accents (`#C9A227`), and clean slate neutrals.
- **Light / Dark Mode:** Integrated theme toggle with persistent preferences stored in `localStorage` (defaults to dark mode inspired by high-end minimal portfolios).
- **Animated Performance Metrics:** Dynamic counters tracking monthly invoice volumes (200+), accounts reconciled (15+), accuracy rates (99.8%), and years of active financial experience (3+).
- **Comprehensive Competency Matrix:**
  - Banking & Cash Management (Bank reconciliation, NEFT/RTGS/UPI, Cheque processing, Cash flow monitoring)
  - Accounting & Reporting (General ledger, Trial balance, Month-end closing, Variance analysis)
  - Compliance & Risk (KYC & AML diligence, Audit support, Fraud detection, GST/TDS tax preparation)
  - Technical Software (Tally ERP 9, Tally Prime, Advanced MS Excel, QuickBooks, Core Banking)
- **Career Timeline:** Detailed achievements from tenure at **RMJ Motors** (reduced month-end closing from 8 to 5 days, 20% AR recovery, zero major audit findings).
- **Credentials & Education:** Bachelor of Commerce (B.Com) + certifications in Tally, GST/TDS, and Financial Excel Modeling.
- **Interactive Contact & CV:**
  - Working inquiry form with validation and simulated feedback
  - Direct contact cards (one-click email copy, direct phone link, LinkedIn)
  - Built-in Curriculum Vitae modal with PDF/print summary download

## 🚀 Live Preview & Deployment

This project is built as a zero-dependency, ultra-fast single page application (`index.html`) using modern Tailwind CSS and Lucide Icons.

### Running Locally
Simply double-click `index.html` or open it with any web browser:
```bash
# Or via local static server
npx serve .
```

### 1-Click Deployments
- **GitHub Pages:** Go to repository **Settings** → **Pages** → Source: **Deploy from a branch** (`main` / root) → **Save**.
- **Vercel / Netlify:** Import the GitHub repository `Anurag13075/Aman-portfolio` directly. No build command needed.
